🎧 OS Audio Loopback & System Bridge 100% Banner-Free

How to route system audio, YouTube Music, DAWs, and desktop sound into XTM without Chrome's "Sharing to this tab" banner.

🖥️ Method 1: Entire Screen Capture All Platforms · No Setup Needed

If you prefer using the browser without configuring OS virtual audio cables:

  1. In the XTM Settings Drawer (top-left gear icon), set System Audio Capture Mode to Entire Screen (Recommended).
  2. When Chrome opens the share picker, make sure Entire Screen is selected and check "Also share system audio".
  3. To hide the sharing indicator: Chrome places a small floating pill at the bottom of the screen instead of pinning a permanent top banner. Click the "Hide" button on that bar. It immediately disappears completely, even in Fullscreen mode!

🐧 Method 2: Linux PipeWire & PulseAudio Native Monitor (Feedback-Free) Linux

Linux features native kernel-level and server-level audio monitoring. Every audio output device in Linux already has a built-in .monitor stream that taps what is playing through your speakers directly into software, completely bypassing screen capture and avoiding any microphone feedback.

  1. Recommended (100% Feedback-Free via pavucontrol GUI):

    Open pavucontrol (Volume Control). Go to the Recording tab while XTM is listening in Chrome/Firefox. Find Google Chrome (or your browser) and change its input dropdown from your physical Microphone to "Monitor of Built-in Audio Analog Stereo" (or "Monitor of [Your Speakers/Headphones]").

    This streams crystal-clear desktop sound (YouTube, Spotify, DAWs) with 0% microphone pickup and 0% feedback risk!

  2. Check Built-in Monitor Devices directly in XTM:

    In XTM's Settings Drawer under Audio Input Device, look for devices tagged with 🎧 [OS Loopback · Banner-Free] (e.g. Monitor of Built-in Audio Analog Stereo). If present, simply select it!

  3. Optional: Dedicated Virtual Null-Sink Cable (Silent & Isolated):

    To create a safe virtual audio cable that does not route to physical speakers:

    pactl load-module module-null-sink sink_name=XTM_Bridge sink_properties=device.description="XTM_Virtual_Audio_Cable"

    To remove it at any time: pactl unload-module module-null-sink

⚠️ Warning on Feedback: Never run bare pactl load-module module-loopback without specifying source and sink! Bare loopback links your physical microphone directly into your speakers, creating an immediate acoustic feedback screech. If you ever loaded one by accident, immediately run: 
pactl unload-module module-loopback
Pro Tip: Audio monitor sinks stream raw 32-bit float / 24-bit PCM with zero browser banners, 0% CPU overhead, and sub-millisecond meter synchronization.

🪟 Method 3: Windows Stereo Mix or Virtual Cable Windows 10 / 11

Windows has a built-in "Stereo Mix" feature on most soundcards, or you can use a free virtual cable:

  1. Enable Built-in "Stereo Mix":
    • Press Win + R, type mmsys.cpl and press Enter to open the Sound Control Panel.
    • Click the Recording tab.
    • Right-click anywhere in the white space and ensure "Show Disabled Devices" is checked.
    • Right-click Stereo Mix (or "What U Hear") and click Enable.
  2. In XTM: Open the Settings Drawer, click "Bridge OS System Audio" or select Stereo Mix in the Audio Input Device dropdown.
  3. If your soundcard lacks Stereo Mix: Install the free VB-Audio Virtual Cable. Set Windows playback to CABLE Input, and select CABLE Output in XTM.

🍎 Method 4: macOS BlackHole Virtual Audio Bridge macOS

macOS does not allow direct system loopback without a virtual driver:

  1. Install the free open-source BlackHole (2ch) audio loopback driver: 
    brew install blackhole-2ch
  2. Open Audio MIDI Setup (in Applications > Utilities).
  3. Click the + button at the bottom left and select Create Multi-Output Device.
  4. Check both your Built-in Output / Headphones and BlackHole 2ch.
  5. In macOS System Settings > Sound, set output to the Multi-Output Device.
  6. In XTM, select BlackHole 2ch under Audio Input Device. You will hear audio normally while XTM visualizes it banner-free!
